# Coach skills

Coach skills can be used at any FounderOS stage. They gate nothing. They never
pass or fail a founder, and they write nothing to the gate record. A coach
reaches for one when a founder gets stuck on something outside the current
stage's cards: blaming others for a miss (`extreme-ownership`), too many
priorities (`the-one-thing`), a decision going in circles (`mental-models`), or
a need for the right thing to read (`pg-essays`).

They use `type: coach-skill`, which is new. The content lint only checks
`skills/*/SKILL.md`, so it does not validate these files yet.
