# Coach: The ONE Thing

A coach skill. It works at any stage, it never blocks or passes a gate, and it
writes nothing to the gate record.

## When to reach for it

The founder has a list of twelve things and is doing a bit of each. A landing
page tweak, three feature ideas, a podcast invite, a pricing rethink, some
interviews "when there's time". The stage they are in needs one of those, and
it is usually the uncomfortable one.

## What to do

1. Pull up the founder's current stage and the gate evidence it still lacks.
   That is the frame for everything below.
2. Ask the Focusing Question, Keller and Papasan's name for it, in this week's
   terms: which single task would make most of the other eleven easier, or
   let you drop them?
3. Check the answer against the gate. At stage 3 it is nearly always "book and
   run the next interviews", not "polish the deck".
4. Put it in the calendar before the call ends: a named slot on Monday,
   Wednesday and Friday, phone in another room. If it is not on the calendar,
   it will lose to Slack.
5. Ask what they will say no to so the block survives. Write the no down.

## Guardrails

- One thing per week at a time. If they name two, ask which one makes the other
  easier.
- This picks the order of work. It never changes what the gate asks for.

## Sources

The ONE Thing, Gary Keller with Jay Papasan. The Focusing Question and time
