# The first bowling pin is a segment small enough to win outright

Start with one narrow group you can dominate, chosen because winning it makes
the next group easier to win.

The picture is a set of pins: knock the first one down cleanly and it takes the
next ones with it. A good first pin is small enough that a solo founder can
reach most of its members, feels the problem hard, and has members who talk to
each other, so word travels. The pins after it are linked to it by something
real: shared members, a shared tool, the same supplier or the same events. A
first pin that is just a job title ("marketers") is still the whole alley.

Credit: Chris Dixon's "The bowling pin strategy", after Geoffrey Moore's
Crossing the Chasm. Read the original: https://cdixon.org/2010/08/21/the-bowling-pin-strategy
