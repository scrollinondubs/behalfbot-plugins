# A gate passes on ledger evidence, never on the founder's word

A FounderOS gate is decided by rows in the founder's ledger: artifacts,
pains, interviews, PR/FAQ versions and the audits on them. Saying the work is
done is not evidence that it was.

This is what makes the gates worth having. Every founder believes their
interviews went well and their audience is real. The gate asks to see the
quotes with links, the interviews with dates and next steps, the commitment
that cost someone something. A decision cites the rows it rests on, so anyone
can check it later. From stage 3 onward, a pass also needs Sean's sign-off,
because the evidence gets harder to judge and the cost of a false pass grows.

This note describes FounderOS's own rule. It is enforced in the ledger schema
and in the stage skills.
