# Test the assumption that is most expensive to be wrong about

Every plan rests on guesses. The riskiest assumption is the one that, if false,
sinks the business, and it is the one to test first.

Rank guesses by two things: how likely you are to be wrong, and what being
wrong would cost. A wrong guess about which reminder channel users prefer costs
an afternoon. A wrong guess about whether anyone will pay costs the company.
Founders tend to test what is easy or what they expect to confirm, which is how
the dangerous guess survives untouched until launch. A guess can only be tested
if it is written so a result could prove it false: a who, a number and a
threshold.
