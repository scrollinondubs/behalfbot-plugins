# Full transitive closure of flights==0.9.0, every package pinned exactly.
# This is the pip equivalent of the committed lockfile CONTRIBUTING.md asks for:
# nothing resolves at install time, so an install cannot pick up a version no
# human chose.
#
# Generated against the platform the chassis actually runs on, not a developer
# laptop - a macOS freeze carries different markers and different wheels:
#
#   docker run --rm python:3.12-slim sh -c "pip install -q flights==0.9.0 && pip freeze"
#
# Regenerate with that command when the pin in requirements.txt moves.
#
# No --hash pins, deliberately. curl_cffi ships platform-specific binary wheels,
# so a hash set is only valid for one arch and one Python minor, and would fail
# an install on any other. Version pinning is what protects the install here;
# the hashes would protect nothing extra while breaking arm64 hosts. Flagged
# rather than left silent, because it is a real deviation from the rule.
